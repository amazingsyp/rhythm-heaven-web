# Smooth Operator 🪒

A one-button rhythm game about plucking stubborn stubble.

**▶ Play now:** https://amazingsyp.github.io/rhythm-heaven-web/

## How to play

Hairs sprout from a gentleman's chin in a rhythm — listen closely.
Four beats later, the tweezers sweep by. **Repeat the rhythm you heard** to pluck every hair.

- **Mobile:** tap anywhere
- **Desktop:** press `Space` or click

Timing matters: a perfect pluck pulls the hair clean out, a sloppy one leaves it bent,
and a miss leaves the poor man hairy and teary.

## Features

- 15 rounds with escalating rhythm patterns — offbeats, eighth-note runs, 16th-note bursts
- Web Audio clock-based judgement (±40ms perfect window) with audio latency calibration
- Works offline-light: plain HTML/JS/CSS, no build step, no dependencies
